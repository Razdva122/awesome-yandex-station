# awesome-yandex-station

Каталог программ для Яндекс Станций с root-доступом. Здесь можно найти музыкальные плееры, локальных голосовых ассистентов, панели управления и плагины. В карточках описано, что каждая программа добавляет Станции. Модели, прошивки, требования и скриншоты собраны в подробностях.

[Открыть каталог](https://razdva122.github.io/awesome-yandex-station/) · [Предложить проект](https://github.com/Razdva122/awesome-yandex-station/issues/new?template=suggest-project.yml)

## Как предложить свой проект

1. Откройте [форму предложения](https://github.com/Razdva122/awesome-yandex-station/issues/new?template=suggest-project.yml).
2. Укажите название программы, ссылку на публичный репозиторий и в одном или двух предложениях объясните, что она добавляет Станции.
3. Если есть данные о совместимости, укажите проверенные модели, точные версии прошивок и ссылку на README или отчёт о проверке. Можно приложить скриншот интерфейса и перечислить зависимости.
4. Отправьте предложение. Оно появится в Issues, где можно уточнить детали и обсудить карточку.

Можно сразу открыть pull request с новой записью в [catalog.json](catalog.json). Возьмите за образец существующую карточку. Для исправлений укажите, какой проект нужно обновить, и приложите источник новых сведений.

## Как устроены карточки

- Короткое описание отвечает на вопрос «Что я смогу делать со Станцией?».
- Модели берутся из списка `models` в [catalog.json](catalog.json). Для каждой модели укажите статус `tested`, если есть подтверждение работы на устройстве, `declared` для заявленной поддержки, `experimental` для экспериментального профиля или `emulated` для проверки на стенде.
- В `firmware` сохраните версию прошивки в том виде, в каком её указал источник. Если версия неизвестна, оставьте поле пустым или опустите его. В `source` можно сослаться на конкретный отчёт.
- Скриншот необязателен. Если добавляете изображение, укажите в `screenshot` путь к файлу, текстовое описание, исходную ссылку и размеры.
- Число звёзд GitHub берётся из сохранённого снимка на дату `checkedAt`.

## Локальный запуск

Из корня репозитория запустите:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальный каталог](http://127.0.0.1:8000/). Установка зависимостей и сборка не нужны. Проверки каталога запускаются командой `node --test`.

## Публикация

GitHub Actions запускает тесты для pull request в `main` и публикует сайт в GitHub Pages после обновления `main`, если проверки прошли. Публикацию также можно запустить вручную на вкладке **Actions → GitHub Pages → Run workflow**. Для нового форка выберите **Settings → Pages → Source → GitHub Actions**.
